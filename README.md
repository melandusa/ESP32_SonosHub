# ESP32 SonosHub

Einfache Sonos-Fernbedienung für ältere Menschen: Radiosender per Kachel starten, Lautstärke,
Aus. Touch-Display Guition ESP32-S3-4848S040 (480×480), steuert einen Sonos-Lautsprecher im
Heimnetz über UPnP/SOAP. Dazu eine Linux-Simulation (SDL) zum Entwickeln und Testen.

Alles Weitere in [sonos-display/README.md](sonos-display/README.md).
